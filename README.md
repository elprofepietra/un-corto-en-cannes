# Un Corto en Cannes — Gerenciamiento de Proyectos (UADE)

Material de ejercitación previa al examen, basado en el caso **"Un Corto en Cannes"** (FACO · DEGES, Docente: Lic. Ornela Palombo).

Alcance resuelto: **Project Charter, Scope Statement (exclusiones), WBS, listado de actividades, diagrama de red (AON / CPM) y diagrama de Gantt**, sin costos.

## Contenido de este repositorio

- **`presentacion_un_corto_en_cannes.pptx`** — Presentación paso a paso con la resolución completa del caso.
- **`index.html`** — Videojuego interactivo para practicar: armado de la lista de actividades, del diagrama de red y del Gantt, con corrección automática y cálculo del camino crítico.
- **`resolucion.md`** — Resolución en texto (Project Charter, Scope, WBS, listado de actividades, red y Gantt).

## Resultado clave del caso

Duración total del proyecto: **16 semanas**. Camino crítico: **C → D → E → N → O** (Perfiles de actores → Audición → Contratación de actores → Rodaje → Entrega de material), sin holgura.
